# Flow Handoff: Characters and Video Ideas

Everything a local Claude session (Claude Code or Claude in Chrome) needs to make
this channel's characters and Shorts in **Google Flow**. This file stands alone:
paste it into the session or point the session at it.

---

## Instructions for Claude (read first)

You are helping make a faceless, cute-and-weird animated YouTube Shorts channel.
The owner has **Google Flow** open in Chrome and is logged in.

**Rules**
- Use **Google Flow only** to make images and videos.
- **Never use OpenArt.** It is reserved for one of the owner's clients and may
  only be used when the owner says so explicitly.
- Don't use other paid generators (Higgsfield, etc.) unless the owner asks.
- Before spending Flow credits on video, confirm the plan with the owner.
- No real brands, logos or Roblox assets in any prompt.

**Step 1: Characters (image mode)**
1. Ask the owner which duo to make (see the table below), or make all 8 if they say so.
2. For each character, paste its **image prompt** (it already includes the style line).
3. Generate 2–4 options, show them to the owner, and keep the one they pick.
4. Save the pick as a Flow **ingredient** named after the character (e.g. `Blip`).
5. Then make the **duo image** using both saved ingredients plus the duo prompt.
6. Optional: make a **character sheet** for the chosen duo (prompt below).
7. Download every picked image and name it like
   `research/characters/1-blip.png`, `1-moss.png`, `1-blip-and-moss.png`.
   Replace the old `.svg` sketches in `research/video-ideas-and-characters.md`
   with the new `.png` files.

**Step 2: Videos (video mode, 9:16)**
1. Use both character ingredients together in every clip so they stay consistent.
2. Use the **video prompt** for each idea in Part 2. Replace `[Kid]` and `[Buddy]`
   with the chosen duo's names (Kid = the chaotic one, Buddy = the calm one).
3. Keep clips silent (no dialogue). Sound effects are added in the editor later.
4. Ideas longer than one clip: generate each beat as its own clip, then join them.

**Style line** (already inside every prompt below; reuse it for anything new):
> Style: cute and slightly weird 3D cartoon character, soft rounded shapes, clean
> bold outline feel, smooth clay-like materials, bright saturated colors, soft
> studio lighting, simple pastel background, full body, front view, expressive
> face, made for YouTube Shorts mascots, no text, no logos.

## Part 2: 30 video ideas with Flow video prompts

**Structure for every idea:** hook in the first 1–2 seconds → setup → escalation →
payoff → an ending that loops back to the start. **Length:** 15–35 seconds.
**Titles:** short and plain, as shown. Reuse the exact title for sequels.

Every video prompt starts with this prefix (shown here once, so the prompts stay short):
> `Vertical 9:16 short. [Kid] and [Buddy] from the reference images.`

…and ends with this suffix:
> `Cute 3D cartoon clay style, exaggerated squash-and-stretch, comedic timing, soft lighting, no dialogue, no text.`
